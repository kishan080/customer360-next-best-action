Cortex AI Functions

  • SENTIMENT(text) → score -1 to +1
  • COMPLETE('mistral-7b', prompt) → summary, topic, intent, urgency
  • DATA_AGENT_RUN(agent, request) → conversational response

Key Objects

  • SV_CUSTOMER_360 — Semantic View (15 verified queries)
  • SVC_CUSTOMER_DOCS — Cortex Search Service
  • CUSTOMER360_AGENT — Cortex Agent (auto model)
  • DT_CUSTOMER360 — Dynamic Table (TARGET_LAG = DOWNSTREAM)

RBAC — 4 Roles, Flat Hierarchy

  • C360_DATA_ENGINEER — owns RAW + ANALYTICS
  • C360_SERVICE_APP — reads ANALYTICS, writes DECISION
  • C360_AUDITOR — read-only DECISION + ANALYTICS
  • C360_ADMIN — DB + warehouse owner

Agent Orchestration

  • Tool 1: Analyst1 — cortex_analyst_text_to_sql → SV_CUSTOMER_360
  • Tool 2: Search1 — cortex_search → SVC_CUSTOMER_DOCS
  • Workflow: Name → customer_id (Analyst) → filter docs (Search) → combine
  • Guardrails: No technical details, no error codes, business-only responses

Risk Signal Engine

  • 8 signals: renewal_proximity (0.20), sentiment_negative (0.20), sentiment_trend (0.15), payment_risk (0.15), complaint_activity (0.10), claim_activity (0.10), engagement_drop (0.05), cross_sell_gap (0.05)
  • Tiers: critical ≥0.75, high ≥0.50, medium ≥0.25, low <0.25

NBA Action Library

  • 8 actions: Retention Outreach, Renewal Reminder, Complaint Follow-Up, Claim Escalation, Billing Assistance, Cross-Sell Home, Cross-Sell Umbrella, No Action
  • Scored: relevance × safety → ranked with evidence
